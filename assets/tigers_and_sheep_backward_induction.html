The key backward-induction step

If one tiger attacks, it becomes the new sheep. The state therefore changes from N tigers + 1 sheep to N−1 tigers + 1 sheep.

Build the pattern from the base case

Tap a state to inspect why it alternates.

Base case

N = 1 → attack

The only tiger can eat the sheep and nobody remains to eat it afterward.

Recurrence

State(N) depends on State(N−1)

A tiger attacks exactly when becoming the sheep in the N−1 state is safe.

Result

Even N → sheep survives

Odd N → one tiger attacks. Even N → every tiger is deterred.

For 100 tigers: 100 is even → attacking would leave 99 tigers with the attacker as sheep → that sheep would be eaten → therefore nobody attacks → the original sheep survives.
